# (WIP) LeetCode CLI in Rust

If you somehow landed on this repo, you should probably use one of the more mature [alternatives on GitHub](https://github.com/search?q=leetcode+cli&type=repositories). 

The end goal is to create something similar to the [Exercism CLI](https://exercism.org/docs/using/solving-exercises/working-locally), but for [LeetCode](https://leetcode.com/) with support for:

* Downloading problems and test cases
* Submitting solutions to your account

The motivation is that if I'm going to be solving LeetCode problems to prep for interviews, I'd rather do it in my own dev environment.

Rather than using an existing tool, I'm building this myself as a learning exercise because I've never written a Rust CLI tool before. I'm writing the code myself but using LLMs as mentors/reviewers, thus the weird AGENTS.md file.
